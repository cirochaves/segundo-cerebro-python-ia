## Tema

Python e APIs de IA para iniciantes: a primeira etapa da minha trilha para Forward Deployed Engineer (FDE)

## Objetivo, em uma frase

Ter um tutor que me ensine, só com as aulas que eu escolhi, o Python e o uso de APIs de IA de que preciso para escrever meu primeiro script que classifica leads com IA.

## Por que este tema

Sou gerente comercial e estou migrando para a área técnica. A vaga que eu miro é a de Forward Deployed Engineer, que junta atendimento ao cliente com código em produção. O primeiro degrau é sair do zero em Python e conseguir chamar uma API de IA.

## O que o segundo cérebro precisa saber

- Terminal do Linux: navegar em pastas e rodar um script
- Python básico: variáveis, tipos, operadores, condicionais, laços, listas, dicionários e funções
- Arquivos: ler e gravar texto, CSV e JSON; tratar erros
- Git e GitHub: versionar e publicar o código
- APIs: o que são, HTTP e REST, chave de API, variáveis de ambiente e ambiente virtual
- API do Claude e engenharia de prompt: fazer a primeira chamada e escrever um prompt de classificação

## Critérios para uma fonte entrar

- Aula em português, para iniciante
- Prática e direta ao tema, sem tutorial de instalação
- Prioridade para o Curso em Vídeo (Gustavo Guanabara)
- Documentação oficial quando existe
